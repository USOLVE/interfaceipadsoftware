# Assets Images

Placez vos images dans les dossiers appropriés :

## wallpapers/
- **default.jpg** (2732x2048px) - Fond d'écran par défaut pour lock screen et home screen
- Ajoutez d'autres fonds d'écran au besoin

## app-icons/
Icônes d'applications (180x180px recommandé) :
- **messages.png** - Icône Messages (vert)
- **facetime.png** - Icône FaceTime (vert)
- **safari.png** - Icône Safari (bleu)
- **photos.png** - Icône Photos
- **mail.png** - Icône Mail
- **calendar.png** - Icône Calendrier
- **notes.png** - Icône Notes
- **settings.png** - Icône Réglages
- **files.png** - Icône Fichiers
- **music.png** - Icône Musique
- **default.png** - Icône par défaut

## contact-photos/
Photos de contacts pour les appels et messages (400x400px recommandé) :
- **default.jpg** - Photo par défaut
- **gm.jpg** - Game Master
- **agent.jpg** - Agent secret
- Ajoutez vos propres photos de contacts

## ui-elements/
Éléments d'interface système (optionnel) :
- Icônes batterie, wifi, signal, etc.

---

**Note**: Pour les tests, des images de placeholder seront utilisées si les fichiers ne sont pas trouvés.

**Sources d'images gratuites** :
- [Unsplash](https://unsplash.com) - Photos haute résolution
- [Pexels](https://pexels.com) - Photos libres de droits
- [Flaticon](https://flaticon.com) - Icônes (vérifiez les licences)

**Formats recommandés** :
- Wallpapers : JPG (optimisé pour le web, < 500KB)
- Icônes : PNG (avec transparence)
- Photos de contacts : JPG (< 200KB)
